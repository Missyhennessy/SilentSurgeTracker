## 🧮 Silent Surge Score (SSS): Formula Design

We’ll calculate it on a 100-point scale using weighted factors. Each component gets normalized to ensure comparability across assets.

### 📊 Formula Overview

Copy

```text-sm font-ligatures-none
SSS = W1(BAM) + W2(TVA) + W3(CCI) + W4(AP) + W5(HHR) + W6(HV)

```

Where:

- **BAM** = Behavioral Activity Metric

- **TVA** = Token Velocity Anomaly

- **CCI** = Community Cohesion Index

- **AP** = Anchor Pressure

- **HHR** = Hype-to-Hold Ratio

- **HV** = Historical Volatility (used as a balancing measure)


## 🧠 Component Breakdown & Calibration Strategy

| Metric | Description | Sample Calibration Strategy |
| --- | --- | --- |
| **BAM (Behavioral Activity)** | Tracks influential wallet deviation from baseline behavior | Compare wallet activity vs. 30-day average; spike = + points |
| **TVA (Velocity Anomaly)** | Token velocity deviation from historical "normal" | Use Z-score of velocity change, filter out noise from bots |
| **CCI (Community Cohesion)** | Measures unity of positive sentiment among holders | NLP-based clustering; more overlap in keyword context = higher score |
| **AP (Anchor Pressure)** | Stability from long-hold wallets | % of supply held >90 days; higher ratio = stronger score |
| **HHR (Hype-to-Hold Ratio)** | Social buzz vs. actual holding conviction | Low memes + high retention = better SSS |
| **HV (Historical Volatility)** | Smooths out fake spikes; penalizes pump patterns | Normalize recent volatility against long-term trend; acts as a score dampener if too erratic |
